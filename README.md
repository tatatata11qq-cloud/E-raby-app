# إعرابي (E'raby) — تعلّم النحو… وأتقن الإعراب

منصة عربية: مستويات ← جزئيات ← محتوى (درس / فيديو / ملف / اختبار) مع روابط Google Drive، ونتائج الطلاب، ورسائل بين الطالب والمدرّس، ولوحة تحكم للمدرس والمدير.

## التشغيل
```bash
npm install
npm run dev          # تطوير
npm test             # اختبارات الأدوات
npm run build        # ملفات النشر في dist/
```
الإعدادات في `.env` (انسخ `.env.example`). القيم ليست أسرارًا؛ الأمان من قواعد Firestore.

## إعداد Firebase (مرة واحدة)
1. فعّل **Authentication ← Email/Password** وأنشئ **Firestore**.
2. انشر القواعد: `firebase deploy --only firestore:rules` (الملف `firestore.rules`).
3. سجّل حسابك من الواجهة، ثم من Firebase Console افتح `users/<uid>` وغيّر الحقل `role` إلى `admin`. بعدها يرقّي المدير الآخرين إلى مدرسين من صفحة «المستخدمون».

## الأدوار
- **طالب:** يتصفح المستويات، يحل الاختبارات (تُحفظ أفضل نتيجة)، ويراسل المدرّسين.
- **مدرس:** يدير المستويات والجزئيات والمحتوى، ويرى الطلاب ونتائجهم ويرد على الرسائل.
- **مدير:** كل ما سبق + ترقية المدرسين وحظر المستخدمين وبيانات المؤسسة.

## الأندرويد
`npm run android:add` مرة واحدة، ثم `npm run android:sync` و`npm run android:open`.

## ملاحظات
- لا يوجد Firebase Storage: كل الملفات روابط Google Drive (يجب أن تكون المشاركة «أي شخص لديه الرابط»).
- الإنشاء الذاتي للحساب طالب فقط، وتفرض القواعد ذلك من جهة الخادم.
